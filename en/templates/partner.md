# Template: partner profile (kind: partner)

Copied into `<section>/<slug>/profile.md`. The folder and the rules for keeping it — `entity.md`.
A partner is not a client: money can flow both ways, and in some areas you are competitors. In `decisions.md`
record separately **what was not promised** (for example, exclusivity) — that's the main source of conflicts.
If a deal with a client goes through the partner, the event is logged in both folders, with links to each other;
for each promise, note whose side it is.
