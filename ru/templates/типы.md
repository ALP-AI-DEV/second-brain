# Реестр типов страниц

Поле `type:` в шапке каждой страницы — одно из значений ниже. Новый тип добавляется только
правкой этого файла. Новый **вид сущности** (курс, дело, поездка) — не новый тип, а новое значение
`kind:` у `entity`; его достаточно описать в карте разделов или завести шаблон профиля.

| type | Что это | Шаблон |
|---|---|---|
| `topic` | Тема: идея, методика, понятие | `тема.md` |
| `insight` | Ответ на вопрос, анализ | `вывод.md` |
| `catalog` | Реестр однотипных записей | `каталог.md` |
| `prompt` | Переиспользуемый промт | `промт.md` |
| `document` | Документ, скан | `документ.md` |
| `learning` | Конспект прочитанного | `конспект.md` |
| `note` | Простая заметка, рецепт | `заметка.md` |
| `entity` | Профиль сущности (`профиль.md`), вид — в `kind:` | `сущность.md`, `клиент.md`, `продукт.md`, `партнёр.md` |
| `timeline` | Хронология сущности | `сущность.md` |
| `decisions` | Решения и обещания | `сущность.md` |
| `transcript` | Транскрипт встречи (`_raw/transcripts/`) | — |
| `email-summary` | Выжимка переписки (`_raw/emails/`) | — |
| `draft` | Рабочий черновик (`drafts/`) | — |
| `index` | Каталог, журнал, общая картина | — |
| `meta` | Инструкции и шаблоны (`AGENTS.md`, `templates/`) | — |

Частые `kind:` — `client`, `partner`, `product`, `project`, `course`, `case`. Свои — по-английски
одним словом или по-русски, но единообразно во всей базе.
