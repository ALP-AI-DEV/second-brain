# Операция: разбор входящих (ingest)

Синонимы: ingest, обработай, разбери, разбери входящие, «закинь в мозг».
Без указания файла — просмотри `raw/inbox/`, покажи список и обрабатывай по одному.
**Сначала разбери всё, что можно разобрать без вопросов, а вопросы задай одним блоком в конце.**
Один спорный файл не повод останавливать остальные.

## Что класть, а что нет

| Что | Решение |
|---|---|
| Заметки, идеи, решения, удачные документы и кейсы, промты | ✅ В базу |
| Прочитанное, транскрипты встреч | ⚙️ Выжимка в базу, оригинал — в сырьё |
| Закладки, сервисы | 🔵 Строкой в каталог |
| «Почитать потом» | ⏳ Список ссылок; после прочтения — конспект |
| Задачи из трекера, полные письма | ❌ Ссылка и выжимка, не копия |
| То, что легко гуглится | ❌ Не класть |
| Пароли, ключи, токены | ⛔ Никогда |

## Шаги

1. **Привратник** (см. AGENTS.md).
2. **Сохрани оригинал** — любой уникальный исходник:
   - транскрипт, письмо, документ по сущности → в её `_raw/` (`transcripts/`, `emails/`,
     `documents/`), имя `ГГГГ-ММ-ДД_тема.ext`;
   - остальное (PDF, фото, сканы, тексты) → `raw/assets/` с датой в имени;
   - архив → распакуй в `raw/assets/<имя-архива>/` до удаления архива из inbox;
   - веб-страница (🟢/🟡) → снимок текста в `raw/assets/`, в шапке URL и дата снятия.
     Страница за логином или с личными данными — только ссылка;
   - отдельно не хранится только то, что целиком перенесено на страницу базы.
3. **Куда положить** — по порядку:
   1. **Сначала чувствительность** (что это — «Защитные правила» в AGENTS.md): здоровье, личные
      финансы, документы, семья — в `wiki/личное/` или раздел карты с «наружу: нет»; так и при
      знакомстве, и в фоне. Деловые цены и бюджеты — не повод класть клиента или проект в
      `личное/`. Неясно, чувствительно ли, — спроси, а остальные материалы разбирай.
   2. Карта разделов (`wiki/index.md`) и поиск по базе: есть ли страница или сущность, которую
      надо дополнить, а не создавать новую.
   3. Есть подходящий раздел — страница в нём. Долгая история с событиями (клиент, проект,
      курс) — папка сущности по `templates/сущность.md`.
   4. Раздела нет — `wiki/заметки/`, в шапке `candidate: <какой раздел напрашивается>`. Долгая
      история (клиент, проект) — сразу папкой сущности внутри `заметки/`: обещания и хронология
      ведутся с первого дня, а в раздел папка переедет при перестройке.
      Новый раздел в рамках разбора не создавай: предложи его (`операции/перестройка.md`),
      если таких материалов уже 3+ или начинается долгая работа.
4. **Суть:** 3 ключевых тезиса. Цель пользователя понятна — действуй и назови место в отчёте;
   неясна — предложи место и дождись ответа.
5. **Страница** — по шаблону из `templates/`.
6. **Связи:** `[[ссылки]]` и обратные ссылки. Один источник может затронуть 5–15 страниц —
   уточни факты, отметь противоречия.
7. **Сущности:** источник про сущность — обнови её `timeline.md`, `decisions.md`, открытые вопросы
   в `профиль.md` (правила — `templates/сущность.md`).
8. `wiki/overview.md` — если меняется общая картина.
9. Строка в каталоге `wiki/index.md` — для новых страниц знания и сущностей. Запись в журнал:
   `## [ГГГГ-ММ-ДД] ingest | что обработали`.
10. **Удали исходник из `raw/inbox/`** — только проверив, что копия лежит по пути из шага 2
    (или содержимое целиком в базе).
11. **Проверка второй моделью**, если операция содержательная — `операции/проверка-второй-моделью.md`.

## Особые случаи

- **Письма, задачи, чаты** из подключённых систем: выжимка (кто, что решили, что обещали, сроки)
  и ссылка или ID оригинала.
- **Изображения:** определи тип (документ, рецепт, слайд, медицинская бумага); на странице —
  ссылка на оригинал.
- ⚠️ **Чувствительное** (здоровье, личные финансы, документы, семья) — страницу создавай после «да»,
  если пользователь не просил сохранить именно этот документ.

## Конвертация файлов

Конвертируй во временную папку вне базы и удали её после чтения. Нет нужного инструмента — скажи
об этом и предложи поставить или прислать файл в другом формате.

| Формат | Чем обычно |
|---|---|
| MD, TXT, CSV, JSON, HTML | читается напрямую |
| PDF, JPG, PNG | большинство агентов читают сами; иначе `pdftotext`, распознавание текста |
| DOCX, ODT, RTF, EPUB | `pandoc файл -t markdown` |
| XLSX | python + openpyxl |
| PPTX | python + python-pptx |
